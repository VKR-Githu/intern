    ℹ️ About Project

    AI-Powered Content Generation Platform — B.Tech final-year capstone (static demo).

    NeuraWrite — AI-Powered Content Generation Platform

    This project is an interactive web demonstration of how Prompt Engineering and Generative AI workflows can power a content-generation product. It covers content creation, sentiment analysis, prompt improvement techniques, and analytics visualization — all simulated on the frontend with predefined data.

    🎯 Project Objective

    To demonstrate, through a polished interactive interface, how prompt engineering decisions (category, tone, technique) shape AI content output, and how analytics can visualize such activity.

    🛠️ Technologies Used

    • HTML5 Semantic page structure
    • CSS3 Modern gradients, grid, animations, responsive design
    • JavaScript DOM interaction, SPA-style navigation, simulated logic
    • Chart.js Bar, pie, doughnut, line & radar charts

    ⚙️ Project Workflow

    1. User selects a module from the sidebar.
    2. Prompt + category + tone are captured as inputs.
    3. A predefined sample response is matched and displayed with a simulated loading animation.
    4. Sentiment module matches text against sample keyword datasets.
    5. Analytics page visualizes predefined activity statistics.
    6. History page stores and displays predefined sample records.

    🌟 Applications & Benefits

    • 🧠 Teaches prompt engineering concepts hands-on.
    • ✍️ Demonstrates content workflows for marketing teams.
    • 🎭 Shows how sentiment analysis pipelines present results.
    • 📈 Illustrates AI product analytics dashboards.
    • 🎓 Serves as a fully presentable capstone demonstration.

    ⚠️ Honesty Disclaimer

    All AI outputs, sentiment classifications, and analytics figures in this platform are predefined sample data simulated with frontend JavaScript. No AI model, API, or machine learning algorithm is running behind the scenes. This is clearly labeled throughout the interface for academic integrity.
